BANK LOAN ANALYSIS PROJECT

 1. Project Overview
The Bank Loan Analysis project analyzes loan application data to understand approval and rejection patterns. The goal is to identify important factors associated with loan approval and provide useful insights for banking decision-making.

 2. Business Objective
- Analyze total loan applications.
- Compare approved and rejected applications.
- Understand the relationship between CIBIL score, income, loan amount, and loan status.
- Identify patterns that can help banks improve loan assessment.

 3. Tools and Technologies
- **SQL:** Data querying, filtering, aggregation, and analysis.
- **Power BI:** Interactive dashboard and KPI visualization.
- **Excel:** Data inspection and validation.
- **Python:** Data cleaning and exploratory data analysis.

 4. Dataset Description
The dataset contains 4,269 loan applications with the following fields:
- Loan ID
- Number of dependents
- Education
- Self-employed status
- Annual income
- Loan amount
- Loan term
- CIBIL score
- Residential assets value
- Commercial assets value
- Luxury assets value
- Bank asset value
- Loan status

 5. Key Performance Indicators (KPIs)
- **Total Applications:** 4,269
- **Approved Applications:** 2,656
- **Rejected Applications:** 1,613
- **Approval Rate:** 62.22%
- **Rejection Rate:** 37.78%

 6. Key Business Insights
1. Of the 4,269 applications, 2,656 were approved and 1,613 were rejected.
2. Approximately 62.22% of applications were approved, while 37.78% were rejected.
3. CIBIL score is an important factor to investigate when comparing approved and rejected applications.
4. Annual income and loan amount can be analyzed together to understand applicant borrowing patterns.
5. Applicant assets, education, self-employment status, and loan term can be compared against loan status to identify trends.

7. Recommendations
- Review CIBIL score patterns alongside approval and rejection outcomes.
- Compare loan amounts with applicant income to identify potentially high-risk applications.
- Monitor rejection rates across relevant applicant groups.
- Use data-driven analysis alongside the bank's formal lending policies.
- Regularly monitor loan application KPIs to support consistent decision-making.

8. Challenges Faced
- Checking the dataset for missing or inconsistent values.
- Ensuring loan status categories were correctly represented.
- Calculating accurate application counts and percentages.
- Creating clear and readable KPI cards and charts in Power BI.

 9. Project Outcome
The project provides a consolidated view of loan application outcomes through SQL analysis and a Power BI dashboard. It demonstrates practical skills in data analysis, KPI calculation, data visualization, and communicating business insights.

10. Conclusion
The Bank Loan Analysis project demonstrates how data analytics can help summarize loan application performance and investigate factors associated with approval and rejection. The dashboard helps stakeholders explore the data and make more informed, evidence-based assessments.
